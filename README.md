### 02 — IMAGE CAPTURE AND FACE DETECTION

It all begins with image capture. A camera acquires an image of the user's face. The system then detects the face within that image and identifies important facial landmarks, including the eyes, nose, and mouth.

### 03 — FACIAL FEATURE EXTRACTION

The system must now understand what makes that face distinctive. It extracts relevant facial features and converts them into a numerical representation known as a Face Embedding.

This representation allows the system to process facial information mathematically rather than simply comparing images visually.

**[Pause – 2 seconds]**

### 04 — COMPARISON AND MATCHING

Once the facial representation has been generated, the system compares it with previously stored reference data.

Through this comparison, it calculates a similarity score that indicates how closely the two facial representations match.

### 05 — THE FINAL DECISION

The similarity score is then evaluated against a predefined threshold.

If the score meets or exceeds this threshold, the system grants access. If it falls below it, access is denied.

This is the critical stage where mathematical analysis becomes a real-world security decision.
